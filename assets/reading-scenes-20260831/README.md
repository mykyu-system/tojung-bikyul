# Canva Reading Scenes

These eight text-free Canva artworks are the base scenes for the 144 Final Reading illustrations. The runtime combines each scene with six restrained color atmospheres and three subtle tonal finishes. No illustrated objects or decorative symbols are added over the Canva artwork.
